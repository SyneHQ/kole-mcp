## How to Set on GitHub

### Via Web Interface:

1. Go to: https://github.com/SyneHQ/kole-mcp
2. Click the ⚙️ gear icon next to "About" (top right)
3. Add description (max 350 characters)
4. Add topics (press comma or enter after each)
5. Check: ✅ Include in the home page
6. Optional: Add website URL: https://docs.synehq.com
7. Click "Save changes"

### Via GitHub CLI:

```bash
# Set description
gh repo edit SyneHQ/kole-mcp --description "Query databases with SQL, PostgreSQL, or plain English through MCP. Execute queries, explore schemas, and analyze data using natural language."

# Add topics (one command)
gh repo edit SyneHQ/kole-mcp --add-topic "mcp,mcp-server,model-context-protocol,database,database-tools,sql,postgresql,postgres,mysql,query-builder,natural-language,text-to-sql,claude,claude-ai,ai-assistant,data-analysis,data-explorer,business-intelligence,schema-inspector,database-management,typescript,nodejs,npm-package,developer-tools,productivity"

# Set homepage
gh repo edit SyneHQ/kole-mcp --homepage "https://docs.synehq.com"
```

## SEO-Optimized Description (Full)

For documentation or landing pages:

```
SyneHQ Kole MCP Server is a Model Context Protocol server that enables natural language database queries through AI assistants like Claude. Execute SQL queries, PostgreSQL commands, and plain English questions against your databases. Features include:

• SQL Query Execution - Run standard SQL against any connected database
• PostgreSQL Support - Full psql command support with DDL operations
• Natural Language Queries - Ask questions in plain English, get SQL results
• Schema Discovery - List tables, inspect schemas, and explore metadata
• Multi-Database - Manage and query multiple database connections
• Connection Testing - Verify database connectivity before querying
• Built-in Skill - 50+ query patterns and best practices included

Perfect for data analysts, developers, and anyone who needs to query databases without switching tools. Works with PostgreSQL, MySQL, and other SQL databases. Built on TypeScript with full type safety and the official MCP SDK.

Use cases: data analysis, business intelligence, database administration, schema exploration, ad-hoc queries, reporting, and data science workflows.
```
